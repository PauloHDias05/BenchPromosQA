# BUG-002 - Busca por produto inexistente exibe produtos incompatíveis

## Épico

Busca de Produtos

## Caso de Teste Relacionado

CT-002 - Buscar produto inexistente

## Descrição

Ao realizar uma busca utilizando um termo que não corresponde a nenhum produto cadastrado, o sistema apresenta sugestões de produtos incompatíveis com o termo pesquisado.

## Pré-condição

Usuário deve estar na página inicial e a barra de pesquisa deve estar disponível.

## Passos para Reproduzir

1. Acessar a página inicial.
2. Localizar a barra de pesquisa.
3. Digitar "Copo".
4. Observar os produtos sugeridos pelo sistema.

## Resultado Esperado

O sistema deve informar que nenhum produto foi encontrado ou apresentar a busca sem resultados.

## Resultado Obtido

Ao pesquisar por "Copo", mesmo não existindo produto correspondente cadastrado, o sistema apresenta sugestões de produtos incompatíveis com a pesquisa.
