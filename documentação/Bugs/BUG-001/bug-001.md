# BUG-001 - Busca exibe produtos não relacionados ao termo pesquisado

## Épico

Busca de Produtos

## Caso de Teste Relacionado

CT-001 - Buscar produto existente

## Descrição

Ao realizar uma busca por um produto existente, o sistema apresenta sugestões que não correspondem ao termo informado pelo usuário.

## Pré-condição

Usuário deve estar na página inicial e a barra de pesquisa deve estar disponível.

## Passos para Reproduzir

1. Acessar a página inicial.
2. Localizar a barra de pesquisa.
3. Digitar **"Teclado"**.
4. Observar os produtos sugeridos pelo sistema.

## Resultado Esperado

O sistema deve apresentar apenas produtos relacionados ao termo **"Teclado"**.

## Resultado Obtido

Ao pesquisar por **"Teclado"**, o sistema também apresenta **Notebooks** e **PC Gamer** entre as sugestões.

Média
