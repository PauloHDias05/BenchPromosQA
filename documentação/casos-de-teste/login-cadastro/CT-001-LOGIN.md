# CT-001 - Login com sucesso

## Épico
Login e Cadastro

## Pré-condição
Usuário deve estar na tela de login e possuir cadastro válido.

## Cenário BDD

**Dado** que o usuário esteja na tela de login

**Quando** informar um e-mail e uma senha válidos e clicar em Entrar

**Então** o sistema deve realizar o login e redirecionar o usuário para a página inicial

## Resultado Esperado
O usuário deve ser autenticado com sucesso e redirecionado para a página inicial.

## Resultado Obtido
O mesmo que o esperado.
