# CT-006 - Cadastro com nome menor que 2 caracteres

## Épico

Login e Cadastro

## Pré-condição

Usuário deve estar na tela de cadastro.

## Cenário BDD

**Dado** que o usuário esteja na tela de cadastro

**Quando** tentar realizar o cadastro sem informar um nome válido

**Então** o sistema deve exibir a mensagem "O nome deve ter no minimo 2 caracteres"

## Resultado Esperado

O cadastro deve ser impedido e a mensagem "O nome deve ter no minimo 2 caracteres" deve ser exibida.

## Resultado Obtido

O mesmo que o esperado.
