# CT-001 - Buscar produto existente

## Épico

Busca de Produtos

## Pré-condição

Usuário deve estar na página inicial e a barra de pesquisa deve estar disponível.

## Cenário BDD

**Dado** que o usuário esteja na página inicial

**Quando** informar o nome de um produto existente na barra de pesquisa

**Então** o sistema deve exibir apenas produtos relacionados ao termo pesquisado

## Resultado Esperado

O sistema deve apresentar resultados compatíveis com o produto pesquisado.

## Resultado Obtido

Ao pesquisar por "Teclado" o sistema também sugere Notebook's e PC Gamer
