# CT-004 - Realizar busca com campo vazio

## Épico

Busca de Produtos

## Pré-condição

Usuário deve estar na página inicial e a barra de pesquisa deve estar disponível.

## Cenário BDD

**Dado** que o usuário esteja na página inicial

**Quando** tentar realizar uma busca sem informar nenhum termo

**Então** o sistema não deve sugerir nenhum produto e a mensagem "Digite ao menos 2 caracteres" deve estar visível

## Resultado Esperado

O sistema deve manter o usuário na página atual, não apresentar sugestões de produtos e apresentar a mensagem "Digite ao menos 2 caracteres"

## Resultado Obtido

O sistema não sugeriu nenhum produto e a mensagem esperada se mantém visível
