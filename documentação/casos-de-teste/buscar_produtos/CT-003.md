# CT-003 - Buscar produto utilizando parte do nome

## Épico

Busca de Produtos

## Pré-condição

Usuário deve estar na página inicial e a barra de pesquisa deve estar disponível.

## Cenário BDD

**Dado** que o usuário esteja na página inicial

**Quando** informar apenas parte do nome de um produto existente

**Então** o sistema deve apresentar sugestões relacionadas ao termo informado

## Resultado Esperado

Produtos que contenham ou estejam relacionados ao termo pesquisado devem ser apresentados.

## Resultado Obtido

Ao pesquisar por "Note" o sistema exibe produtos relacionados ao termo pesquisado como Notebooks.
