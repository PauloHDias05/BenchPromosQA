# CT-002 - Buscar produto inexistente

## Épico

Busca de Produtos

## Pré-condição

Usuário deve estar na página inicial e a barra de pesquisa deve estar disponível.

## Cenário BDD

**Dado** que o usuário esteja na página inicial

**Quando** informar um termo que não corresponda a nenhum produto cadastrado

**Então** o sistema não deve apresentar produtos incompatíveis com a pesquisa

## Resultado Esperado

O sistema deve informar que não foram encontrados resultados ou apresentar a busca vazia.

## Resultado Obtido

Ao pesquisar por "Copo" no qual o produto não está cadastrado, o sistema sugere produtos incompatíveis
