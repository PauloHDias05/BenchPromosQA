# CT-005 - Acessar página de Setups

## Épico

Navegação de Páginas

## Pré-condição

Usuário deve estar na página inicial e a opção Setups deve estar disponível.

## Cenário BDD

**Dado** que o usuário esteja na página inicial

**Quando** clicar na opção "Setups"

**Então** o sistema deve direcionar o usuário para a página de Setups

## Resultado Esperado

O usuário deve ser direcionado para a página /setups.

## Resultado Obtido

O mesmo que o esperado.
