# CT-003 - Acessar página de Recomendações

## Épico

Navegação de Páginas

## Pré-condição

Usuário deve estar na página inicial e o link de Recomendações deve estar disponível.

## Cenário BDD

**Dado** que o usuário esteja na página inicial

**Quando** clicar na opção de Recomendações

**Então** o sistema deve direcionar o usuário para a página de Recomendações

## Resultado Esperado

O usuário deve ser direcionado para a página /tier-lists.

## Resultado Obtido

O mesmo que o esperado.
