# CT-002 - Acessar página de Comparação

## Épico

Navegação de Páginas

## Pré-condição

Usuário deve estar na página inicial e o link de comparação deve estar disponível.

## Cenário BDD

**Dado** que o usuário esteja na página inicial

**Quando** clicar na opção de comparação

**Então** o sistema deve direcionar o usuário para a página de Comparação

## Resultado Esperado

O usuário deve ser direcionado para a página /compare.

## Resultado Obtido

O mesmo que o esperado.
