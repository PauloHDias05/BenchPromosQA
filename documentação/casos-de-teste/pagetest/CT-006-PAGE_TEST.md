# CT-006 - Acessar página Encontrar Notebook

## Épico

Navegação de Páginas

## Pré-condição

Usuário deve estar na página inicial e o menu Guias deve estar disponível.

## Cenário BDD

**Dado** que o usuário esteja na página inicial

**Quando** acessar o menu "Guias" e clicar em "Responda algumas perguntas"

**Então** o sistema deve direcionar o usuário para a página Encontrar Notebook

## Resultado Esperado

O usuário deve ser direcionado para a página /encontrar-notebook.

## Resultado Obtido

O mesmo que o esperado.
