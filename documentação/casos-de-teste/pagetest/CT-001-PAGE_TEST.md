# CT-001 - Acessar página de Benchmarks

## Épico

Navegação de Páginas

## Pré-condição

Usuário deve estar na página inicial e o menu Comparar deve estar disponível.

## Cenário BDD

**Dado** que o usuário esteja na página inicial

**Quando** acessar o menu "Comparar" e clicar em "Desempenho real"

**Então** o sistema deve direcionar o usuário para a página de Benchmarks

## Resultado Esperado

O usuário deve ser direcionado para a página /benchmarks.

## Resultado Obtido

O mesmo que o esperado.
