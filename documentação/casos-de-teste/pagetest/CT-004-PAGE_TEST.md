# CT-004 - Acessar página de Sorteios

## Épico

Navegação de Páginas

## Pré-condição

Usuário deve estar na página inicial e a opção Sorteios deve estar disponível no menu de navegação.

## Cenário BDD

**Dado** que o usuário esteja na página inicial

**Quando** clicar na opção "Sorteios" do menu

**Então** o sistema deve direcionar o usuário para a página de Sorteios

## Resultado Esperado

O usuário deve ser direcionado para a página /sorteios.

## Resultado Obtido

O mesmo que o esperado.
